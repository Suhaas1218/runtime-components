# Runtime Components

This repository contains my basic runtime components and configuration files for bash, zsh, vim, git, and gdb.

## Files

- `.bashrc` - Bash configuration
- `.zshrc` - Zsh configuration
- `.vimrc` - Vim configuration
- `.gitconfig` - Git configuration
- `.gdbinit` - GDB configuration
- `install.sh` - Script to install the runtime components
